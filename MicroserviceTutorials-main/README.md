# Microservice Tutorials

## About This Project

This repository contains microservices projects and practical examples based on the tutorials created by **Navin Reddy**.

The original project and educational content were created by Navin Reddy. We are learning from his tutorials to improve our understanding of Java, Spring Boot, Microservices Architecture, and related technologies.

A special thanks to **Navin Reddy** for sharing his knowledge and providing valuable educational resources to the developer community.

## Original Repository

GitHub: https://github.com/navinreddy20/MicroserviceTutorials

## Technologies & Concepts

- Java
- Spring Boot
- Microservices Architecture
- Spring Cloud
- API Gateway
- Service Registry
- REST APIs
- Database Integration

## Project Structure

- `api-gateway` – API Gateway implementation.
- `question-service` – Question Service microservice.
- `quiz-service` – Quiz Service microservice.
- `service-registry` – Service Registry implementation.

## Learning Purpose

This project is part of our continuous learning journey in Java development and microservices.

The purpose is to study the code, understand how different microservices communicate with each other, practice implementation, and develop practical backend development skills.
