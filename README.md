# Java – Projects & Learning Portfolio

Welcome to my Java repository!

This repository is a collection of Java projects, practical implementations, and learning exercises developed throughout my journey as a Java developer.

The main goal of this repository is to strengthen my understanding of Java programming, object-oriented design, backend development, software architecture, and modern application development by working on practical projects.

As I continue learning and developing new applications, this repository will grow to include additional projects and implementations.

---

## Repository Contents

The repository currently contains projects covering different areas of Java development, ranging from fundamental object-oriented programming concepts to Spring Boot, microservices, and full-stack applications.

### 1. Smart Card Transit System

**Folder:** `smart-card-transit-system/`

**Technologies:** Java, OOP, JUnit 4

A Java-based public transportation smart card management system developed collaboratively with a university friend as a final project for our Object-Oriented Programming course.

The application simulates a public transportation payment system with different passenger categories, transportation methods, wallet management, monthly subscriptions, and transaction history.

**Key Concepts:**
- Encapsulation, Inheritance, Polymorphism, and Abstraction
- Factory Pattern
- Strategy Pattern
- State Pattern
- Singleton Pattern
- Facade Pattern
- Repository Pattern
- Dependency Injection
- Unit Testing

### 2. Quiz Application – Monolithic Architecture

**Folder:** `quiz-app-monolithic/`

**Technologies:** Java, Spring Boot, Spring Data JPA, Hibernate, PostgreSQL, Maven

A quiz application developed using Java and Spring Boot, following a monolithic architecture.

The application provides functionality for managing questions, creating quizzes, retrieving quiz questions, submitting answers, and calculating results.

This project is based on the educational work of **Navin Reddy**.

**Key Concepts:**
- Monolithic Architecture
- Spring Boot Application Development
- RESTful API Development
- Layered Architecture
- Spring Data JPA
- Hibernate ORM
- PostgreSQL Integration
- Database Operations

**Original Creator:** [Navin Reddy](https://github.com/navinreddy20)

---

### 3. Quiz Application – Microservices Architecture

**Folder:** `quiz-app-microservices/`

**Technologies:** Java, Spring Boot, Spring Cloud, Microservices

A microservices-based quiz application designed to demonstrate how an application can be divided into smaller, independent services.

The project explores the use of multiple services to manage questions and quizzes, together with service discovery and API gateway concepts.

This project is based on the educational work of **Navin Reddy**.

**Key Concepts:**
- Microservices Architecture
- Independent Services
- API Gateway
- Service Registry
- Inter-Service Communication
- Spring Boot
- Distributed Application Design

**Original Creator:** [Navin Reddy](https://github.com/navinreddy20)

---

### 4. IPL Dashboard

**Folder:** `ipl-dashboard/`

**Technologies:** Java, Spring Boot, Spring Batch, Spring Data JPA, Hibernate, React.js, HSQLDB, Maven, AWS

A full-stack web application for exploring historical Indian Premier League (IPL) cricket statistics and match information.

The application uses a Spring Boot backend and React.js frontend. Historical match data is processed using Spring Batch and stored in a relational database.

This project is based on the educational work of **Koushik Kothagal (Java Brains)**.

**Key Concepts:**
- Full-Stack Application Development
- Spring Boot
- Spring Batch
- Data Processing and Importing
- REST API Integration
- Spring Data JPA
- Hibernate ORM
- React.js
- Frontend and Backend Communication
- AWS Deployment Concepts

**Original Creator:** [Koushik Kothagal – Java Brains](https://github.com/koushikkothagal)
